# Modelagem UML: Diagrama de Casos de Uso com IA - Agenda 11 TI I (Recuperacao)

Atividade de recuperacao da Agenda 11 da disciplina Tecnologias da Informacao I.

## Descricao

Modelagem do Sistema de Matricula Online da ETEC contendo todas as etapas do processo:
1. Analise preliminar de requisitos, atores e casos de uso;
2. Refinamento e validacao conceitual com Inteligencia Artificial;
3. Diagrama formal de Casos de Uso (UML);
4. Relatorio completo de entrega no formato exigido: `Rodrigo_Ag11_TI_I_Recup.docx`.

## Estrutura de Arquivos

- `Rodrigo_Ag11_TI_I_Recup.docx`: relatorio completo para envio no Fichario.
- `diagrama_caso_de_uso.png`: imagem do diagrama de casos de uso UML.
- `interacao_ia.png`: registro da etapa de refinamento com IA.
- `diagrama.html`: codigo-fonte vetorial SVG do diagrama.
- `gerar_relatorio.py`: script de geracao do documento docx.
- `test_validacao.py`: testes automatizados de integridade dos arquivos e artefatos.

## Como Executar os Testes

```bash
python test_validacao.py
```
